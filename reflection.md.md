1. What's the difference between a variable and a constant? A variable is a name memory location that stores data values that can modified or reused throughout your program. A constant is a value that cannot be changed once it's declared.

2. Why was decimal used for money values? Decimal is used for money values because it helps to avoid rounding errors that can occur with floating-point types. Decimal provides a higher level of precision, which is important for financial calculations.

3. What is the purpose of enum? The purpose of an enum is to define a custom data type that consists of a set of named constants. Enums are used to represent a collection of related values in a more readable and maintainable way.

5. What is the difference between implict and explict casting? Implicit casting when a data type is automatically converted to another data type without any loss of data. Explicit casting is when a data type is manually converted to another data type, which may result in loss of data or precision.

7. Why is variabe scope important? Variable scope is important because it determines the accessibility and lifetime of a variable within a program. It helps to prevent naming conflicts and ensures that variables are only accessible where they are needed, which improves code organization and maintainability.
